# Expense & Income Tracker System (Flask + MySQL)

A full-stack web application to track both income and expenses using Flask and MySQL.  
Users can add transactions, view history, and monitor balance in real time.

---

##  Features

-  Add Income & Expense transactions
-  View transaction history
-  Auto calculate total income
-  Auto calculate total expenses
-  Balance tracking (Income - Expense)
-  MySQL database storage
-  Simple Flask web interface

---

##  Tech Stack

- Python 
- Flask 
- Flask-SQLAlchemy 
- MySQL 
- PyMySQL 
- HTML (Jinja2 Templates)
